# 축하 메시지 설문 결과 요약

- 대상: AI NATIVE CAREER CAMP 2기 동기
- 기간: 2026-11-25 ~ 11-26 · 응답 **15명** · 구글 설문(익명, 이름 · 연락처를 받지 않음)
- 원본: [`축하메시지_설문_응답.xlsx`](축하메시지_설문_응답.xlsx)
- 나이대: 30~34세 7명, 25~29세 5명, 35세 이상 3명
- 참고: 설문 도중 성별 문항을 빼고(응답 1건만 있음), 9번 문항을 고르기에서 5점 척도로 바꿨습니다(고르기 1건, 척도 14건). 설문에서는 "오너먼트" 대신 "장식"이라는 말을 썼습니다.

## 핵심 결과

**1. 받은 축하 메시지는 잘 다시 보지 않는다**
- 다시 찾아본 적: 없다 8명, 한두 번 5명, 여러 번 2명
- 다시 보지 않은 이유(8명): "다시 볼 계기가 없다" 7명, "어디 있는지 찾기 어렵다" 1명
- 보낼 때 아쉬운 점(여러 개 선택): 텍스트만으로는 마음을 전하기 어렵다 7, 뭐라고 써야 할지 모르겠다 6, 금방 지나가 버려 기억에 남지 않는다 4
- 주로 쓰는 방법: 카카오톡 개인 메시지 12명, 손편지 · 카드 2명, 단톡방 1명

**2. 모아서 간직하는 것에 대한 반응은 중간 이상, 스노우볼 모양이면 조금 더 높다**
- "한곳에 모아 기념품처럼 간직할 수 있다면" (5점 척도, 15명): 평균 **3.7점** (5점 3명, 4점 5명, 3점 6명, 2점 1명)
- "스노우볼 속 장식으로 모인다면 받고 싶은 마음" (5점 척도, 14명): 평균 **3.9점** (5점 4명, 4점 5명, 3점 4명, 2점 1명)

**3. 가장 큰 걸림돌은 "내가 먼저 부탁해야 한다"는 점**
- "링크를 보내 메시지를 부탁해야 한다면": 부탁하기가 민망해서 안 할 것 같다 **7명**, 특별한 날이라면 해 볼 것이다 3명, 해 볼 것이다 2명, 친구가 대신 만들어 주면 좋겠다 2명, 관심 없다 1명
- 자유 서술(5건)에서도 같은 걱정이 나왔습니다: "링크를 보내 부탁하는 것이 너무 큰 진입 장벽 같다", "받는 쪽도 미루다가 안 할 것 같다", "시간이 지나면 메시지와 큰 차이를 못 느낄 수도 있다", "나만 볼 수 있었으면 좋겠다"

**4. 기능에 대한 선호**
- 메시지를 읽는 때: 달리는 대로 바로 10명, 정해진 날에 한꺼번에 3명, 내가 고르고 싶다 2명
- 이름: 그때그때 고르고 싶다 8명, 익명 4명, 이름을 밝힌다 3명
- 있으면 좋겠는 기능(3개까지 선택): 장식 모양과 색 고르기 11, 스노우볼 꾸미기 7, 새 메시지 알림 6, 메시지에 답장 5, 장식을 달 위치 직접 고르기 4, 메시지에 사진 넣기 3, 이미지로 저장해 공유 3, 배경 음악 3

## 읽을 때 주의할 점

- 응답자가 15명이고 모두 같은 캠프의 동기라, 경향을 보는 정도로만 씁니다.
- 스노우볼 반응(3.9점)과 모아 간직하기 반응(3.7점)의 차이는 작고, 문항 형식이 도중에 바뀌어 엄밀한 비교는 아닙니다.
