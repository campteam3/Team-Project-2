# 축하 메시지 설문

> 대상: 캠프 동기 · 길이: 13문항, 3분 이내 · 이름과 연락처는 받지 않음
> 구글 설문지 만들기: [설문_만들기.gs](설문_만들기.gs) · 예시 이미지: [예시이미지.jpg](예시이미지.jpg)
> 설문에서는 "오너먼트" 대신 "장식"이라고 씁니다. 서비스 화면의 표현은 그대로 둡니다.

## 무엇을 알아보려는가

| 알고 싶은 것 | 문항 | 어디에 쓰나 |
| --- | --- | --- |
| 지금의 방법이 정말 아쉬운가 | 2~6 | PRD 와 발표의 문제 정의 근거 |
| "모아 보고 간직한다"는 가치에 수요가 있는가 | 7, 8 | 서비스의 필요성 |
| 스노우볼이라는 형태가 수요를 키우는가 | 9, 10 | 형태에 대한 반응, 걱정되는 점 |
| 아직 정하지 못한 기능의 방향 | 11~13 | 마감(11/29) 전 범위 결정 |

순서에 이유가 있습니다. 경험(2~6)을 먼저 묻고, 형태를 밝히지 않은 채 가치(7~8)를 묻고, 그다음에 이미지를 보여 줍니다(9~10). 서비스를 먼저 보여 주면 앞 문항의 답이 서비스에 맞춰지기 때문입니다.

## 문항

**응답자**

1. 나이대를 알려 주세요. (20~24 / 25~29 / 30~34 / 35 이상)

**지금까지의 경험**

2. 최근 1년 동안 어떤 일로 축하나 기념 메시지를 보냈나요? *모두 선택* (생일 / 새해·명절 / 크리스마스·연말 / 졸업·수료·합격 / 취업·이직·퇴사 / 결혼·출산 / 보낸 적 없다 / 기타)
3. 그때 주로 어떤 방법을 썼나요? (카카오톡 개인 메시지 / 단톡방 / 인스타그램 등 SNS / 손편지·카드 / 온라인 롤링페이퍼 / 기타)
4. 메시지를 보낼 때 아쉬웠던 점이 있나요? *모두 선택* (텍스트만으로는 마음을 전하기 어렵다 / 뭐라고 써야 할지 모르겠다 / 다른 사람들 메시지에 묻힌다 / 단톡방에서는 남들이 다 봐서 부담된다 / 금방 지나가 버려 기억에 남지 않는다 / 아쉬운 점이 없었다)
5. 내가 받은 축하 메시지를 나중에 다시 찾아본 적이 있나요? (여러 번 있다 / 한두 번 있다 / 없다)
6. 다시 보지 않았다면 이유는 무엇인가요? *선택 응답* (어디 있는지 찾기 어렵다 / 여기저기 흩어져 있다 / 다시 볼 계기가 없다 / 기타)

**이런 것이 있다면** (다음 쪽)

7. 지인들에게 받은 축하 메시지를 한곳에 모아 한눈에 보고, 기념품처럼 간직할 수 있다면 어떨 것 같나요? (전혀 필요 없다 1 ~ 꼭 갖고 싶다 5)
8. 그런 것을 받으려면 내가 친구들에게 링크를 보내 메시지를 부탁해야 합니다. 그래도 해 볼 건가요? (해 볼 것이다 / 생일이나 연말 같은 특별한 날이라면 해 볼 것이다 / 친구가 대신 만들어 주면 좋겠다 / 부탁하기가 민망해서 안 할 것 같다 / 관심 없다)

**예시 이미지를 보고 답해 주세요** (다음 쪽)

> (이미지) 친구들이 보낸 메시지가 스노우볼 속 트리의 장식으로 하나씩 달립니다. 장식을 누르면 메시지를 읽을 수 있어요. ※ 예시 이미지이며 실제 화면과 다를 수 있습니다.

9. 메시지가 이렇게 스노우볼 속 장식으로 모인다면, 받고 싶은 마음이 어떻게 달라지나요? (많이 줄어든다 1 ~ 달라지지 않는다 3 ~ 많이 커진다 5)
10. 걱정되거나 귀찮을 것 같은 점이 있다면 적어 주세요. *자유 서술, 선택 응답*

**어떻게 만들면 좋을까요** (다음 쪽)

11. 받은 메시지는 언제 읽고 싶나요? (달리는 대로 바로 / 정해진 날에 한꺼번에 / 내가 고르고 싶다)
12. 메시지를 남길 때 이름은 어떻게 하고 싶나요? (이름을 밝힌다 / 익명으로 남긴다 / 그때그때 고르고 싶다)
13. 있으면 좋겠는 기능을 3개까지 골라 주세요. (장식 모양과 색 고르기 / 장식을 달 위치 직접 고르기 / 스노우볼 꾸미기 / 배경 음악 / 새 메시지 알림 / 이미지로 저장해 공유 / 메시지에 답장 / 메시지에 사진 넣기)

## 결과를 읽는 방법

- **5번 "없다"의 비율**: "받은 메시지를 다시 보지 않는다"는 문제 정의의 근거입니다. 대부분 다시 봤다고 하면 문제 정의를 바꿔야 합니다.
- **8번에서 앞의 두 보기를 고른 비율**: 실제 수요에 가장 가깝습니다. "친구가 대신 만들어 주면 좋겠다"가 많으면, 내가 만들어 달라고 부탁하는 방식보다 **친구가 만들어 선물하는 방식**이 맞는다는 신호입니다. 7번 점수는 높은데 8번이 낮으면 "받고는 싶지만 부탁하기 민망하다"가 진짜 걸림돌입니다.
- **9번**: 스노우볼이라는 형태가 수요를 키우는지 보여 줍니다. 평균이 3보다 높으면 키운다, 낮으면 줄인다로 읽습니다. 다만 이 반응은 예시 이미지에 대한 것이고, 예시 이미지는 실제 화면보다 완성도가 높습니다.
- **11~13번**: 많이 고른 것부터 범위에 넣을지 판단합니다.

## 한계

- 응답자가 캠프 동기라 표본이 작고 한쪽으로 치우칩니다. 발표에서는 "동기 ○명 대상"이라고 밝히고 참고 근거로 씁니다.
- 인원이 적어 나이대별로 나눠 비교하기는 어렵습니다. 응답자 구성을 설명하는 용도로 씁니다.
- 설문은 "쓰기 쉬운가"를 알려 주지 못합니다. 그것은 상호 테스트에서 실제로 써 보게 하고 성공률과 시간을 잽니다.
