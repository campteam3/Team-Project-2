## 처음 시작하는 팀원에게

1. 저장소를 clone 합니다.
2. `gh auth login`으로 GitHub CLI에 로그인합니다 (에이전트가 이슈와 PR을 다루는 데 필요).
3. [CLAUDE.md](CLAUDE.md)의 "팀과 구간" 표에 본인 줄을 채웁니다 (`git config user.name` 값과 이름).
4. `docs/위임로그/_양식.md`를 복사해 `docs/위임로그/본인이름.md`를 만듭니다.
5. [git.md](git.md)를 한 번 읽습니다.
